Scope note: DataSource.getCell() is synchronous — it's called on every paint. getRows() is declared on the interface as optionally returning a Promise, but nothing in CyExcelCore/ TableStore actually calls it today, so there's no real "fetch more rows as you scroll" behavior yet. What is real: the DataSource itself can be populated from an async source before the table mounts — a custom DataSource below waits on a simulated network request, then serves everything synchronously from an in-memory cache once it's mounted.
