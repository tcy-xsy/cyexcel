操作提示（真实交互）

  • 点击 / 拖拽会移动内部选中的单元格，用来决定双击 / Enter 编辑哪一格—— 目前没有可视的选中高亮框（见"尚未实现"）
  • 方向键、Tab、Home、End 移动这个内部选区
  • 双击、按 Enter 或直接输入字符，会在对应格子位置弹出真实的编辑输入框
  • Esc 取消编辑；中文输入法组合期间不会提前提交
  • 滚动会正确重绘可见行；编辑中滚动会按 scrollCommitPolicy 提交或取消
  • 表格演示了全部 7 个内置 CellType（text / number / boolean / date / select / array / json）加一个自定义的 money 类型（extends: "number"，覆盖 format()）——右侧"读取 / 写入单元格"对每种 类型都做了对应的输入解析（数字、true/false、日期字符串、 逗号分隔的数组、合法 JSON）
