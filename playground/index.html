Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做也能用
调用 sheet.sortByColumn(列, "asc" | "desc")——物理重排行，行高跟着行走， 一次撤销同时还原顺序和行高。可排序的列在表头右端有一对上下小三角，直接点它排序； 当前方向的那个变成蓝色、另一个保持灰色（同 antd Table 的做法——留着灰的那个，才看得出 另一个方向还能再点一次）。再点一次在升/降序间切换，不会回到原始顺序（要找回原顺序 只能撤销）。三角就画在可点击的那条窄带里，所以看到的位置就是要点的位置。 「标签」列没有 ⇅——array/json 没有全序，由类型自己声明 sortable: false；「SKU」列则是在列上写了 sortable: false， 演示列级覆盖
调用 sheet.filterByColumn(列, predicate)——不匹配的行折叠成 0 高度， 存储的行高和数据一个字节都不动，清除过滤逐像素复原。过滤不进撤销栈、 也不会清空已有的重做记录（同自动行高的提交方式）。表头右端第二条窄条 （紧挨着排序小三角左边）点一下会用当前输入框的值对那一列过滤——core 自己不知道 该用什么谓词，点击只发一个通知，谓词由这里（宿主）决定
调用 sheet.find(query, options)——只扫描实际有值的格子（分片让出主线程， 规模再大也不会卡成一个长任务），只返回匹配坐标，不在表格上画额外高亮（同 Excel： 工作表上看不到"全部匹配"，只有当前项用普通选区框标出）。 sheet.findNext()/findPrevious() 在匹配之间循环，把选区 移到那一格并把视口滚过去；replace() 走普通可撤销的单格写入， replaceAll() 对所有匹配一次事务、一次撤销记录
调用 sheet.setRangeStyle(range, patch)——**合并语义**：只改传进去的那个键， 其余保留，传 null 清掉某一个键。整片选区是一次事务、一次撤销记录。 数字格式交给 numfmt（Excel pattern），非法 pattern 在设置时就抛 invalid-number-format，不会等到那一格滚进视口
样式表：0 条 这行显示当前格的样式 id 与 styles 表的条目数——把同一个样式刷到很多格上， 条目数**不会**跟着涨（intern 去重）；这是肉眼验证稀疏存储的唯一直观方式
调用 sheet.copy({ download: true })；Ctrl/Cmd+S 是同一个动作的快捷键 （sheet.registerShortcut() 演示），Ctrl/Cmd+K 切换主题

操作提示（真实交互）

  • 点击 / 拖拽移动选中的单元格（会画出蓝色高亮框），用来决定双击 / Enter 编辑哪一格；Ctrl/Cmd+click 追加不连续区域，Shift+click 延伸最近一次选区
  • 方向键、Tab、Home、End 移动这个内部选区
  • 双击、按 Enter 或直接输入字符，会在对应格子位置弹出真实的编辑输入框
  • Esc 取消编辑；中文输入法组合期间不会提前提交
  • 滚动会正确重绘可见行；编辑中滚动会按 scrollCommitPolicy 提交或取消
  • 表格演示了全部 7 个内置 CellType（text / number / boolean / date / select / array / json）加一个自定义的 money 类型（extends: "number"，覆盖 format()）——右侧"读取 / 写入单元格"对每种 类型都做了对应的输入解析（数字、true/false、日期字符串、 逗号分隔的数组、合法 JSON）
  • 点行号选中一行或拖拽多选几行后，把鼠标移到选区的上/下边缘（会出现一条 插入指示线）按住拖动，可以把这些行重新排列到新位置（rowReorder 选项，插入式移动，不会覆盖/丢失目标位置原有数据）；拖拽过程中按 Esc 可以 取消，拖到可视区域边缘会自动滚动。边缘之外的拖拽仍然是原有的多选，行为 不变
  • 叶子表头里，sku/price/inStock/ status 四列配了自定义标题，其余列没配——没配的那几列显示 电子表格字母（B、D、E...）——列已经没有 id 可当兜底了（ADR 0004 §3.8.2），所以 columnLetterFallback 的默认值翻成了 true，关掉它的意思变成"这一列干脆没有标题"。参考 Univer 的 customizeColumnHeader()：字母和自定义标题同一行二选一， 不是字母行 + 标题行两行堆叠
